# CasaUnoVillas

A concept website built for **Casa Uno Villas** — three private-pool villas in Purok 4, Barangay Santo Domingo, Lubao, Pampanga.

`pitch/casa-uno-villas.html` is a single self-contained page (no build step, no backend, no external assets). Open it in a browser.

It includes a working front-end booking flow:

- Availability calendar with blocked dates and range validation
- Live pricing — weekday/weekend nights, extra-guest charges, 50% deposit
- Direct-vs-Airbnb price comparison
- Photo gallery with lightbox
- Light/dark themes

Villa capacities, bed and bath counts, review scores and Airbnb comparison prices are the property's own, checked August 2026. Direct nightly rates are a proposed structure, not published pricing.
